Calendar's User Documentation

Event manager — Category manager — Tasks — Settings — Reminders — Scripting — Help


Calendar is a native Haiku application to manage your appointments. It was originally developed by Akshay Agarwal for the Google Summer of Code of 2017, see his Blog posts about it. This edition is developed and maintained at sikosis/Calendar.

You can create, edit and delete events, and cancel or hide them, categorize events and show them in a day, week or month view.

At the top left is today's date (click it to jump back to "today" from whenever you are in the calendar). Below is a calendar view, highlighting the currently shown date. Days with events are tinted as well; the more events on a day, the darker they get. Go figure... :)

To the right is the actual list of events. With the tabs at the top, you set the view to show all events for that Day, Week, or Month.

The Filter field narrows the event list automatically as you type. Delete the filter text or click Clear to show all events again.

Right-click an event to get a context menu to create a New event, or Edit, Delete, Cancel or Hide an existing event.
Hidden and deleted events can remain visible by activating View | Show hidded/deleted events and are then tinted red. Deleted events are moved to the system's Trash. If you empty the Trash, your events will be truely gone and cannot be "un-deleted" any more!

Event manager

Double-clicking an event also edits an event. As when creating a new event, it opens the Event manager.

The Event manager lets you set all the details of an event:

  • Add a Name, Place and Description.
  • Define as an All day event or set Start/End date and time (click the "▼" button for a pop-up calendar for the date, the time setting is HH:mm (24-hour format)).
  • Optionally choose a Recurrence: daily, weekdays, weekends, weekly, monthly or yearly. Monthly events on a day that does not exist in a shorter month occur on that month's last day.
  • Set the Status to Cancelled or Hidden (also done with the context menu of the main window).
  • Optionally give it a Reminder.

Category manager

You can create and edit event categories by invoking Category | Manage....

Calendar comes with only two categories preinstalled: "Default" and "Birthday". The "Default" category cannot be deleted but can be modified. Click on New... or select a category and click Edit... to open the Category edit window:

Here you simply enter the name of the category and choose a color for it.

Tasks

Event | Tasks... opens Calendar's own scheduled task manager. It lists tasks saved in Calendar's settings and provides New..., Edit... and Delete controls.

A task consists of a schedule and a command. The schedule accepts five minute, hour, day-of-month, month and day-of-week fields, such as 0 9 * * 1-5. Lists, ranges and steps are supported, as are @reboot, @hourly, @daily, @weekly, @monthly and @yearly.

The persistent Calendar Deskbar replicant checks these tasks once per minute and launches matching commands through /bin/sh as the current user. It continues scheduling while the main Calendar window is closed. Choosing Quit Calendar from the replicant stops the scheduler and removes the replicant.

Settings

App | Settings... opens a window with a few available options:

  • Set the Default category for newly created events.
  • Have the First day of the week either to whatever the system locale says, or choose a specific day.
  • Choose to Show week numbers in calendar.
  • Choose the Bar colour used to separate days in week view and weeks in month view.

Reminders

You can set reminder for any event in the Calendar while creating the event (or while editing it afterwards). The reminder appears in the form of a system alert, which contains Event Name, Event Place, and the time remaining till the event. It takes help of a Daemon, or basically a background application, which enables it to deliver the reminders even if the Calendar application is not open.

Calendar Daemon was developed under Google Summer of Code 2022 by Harshit Sharma, see his wrap up blog post about it.

Scripting

Calendar supports Haiku scripting through hey. Calendar must be running before sending it commands. To inspect the complete scripting vocabulary, enter:

hey Calendar GETSUITES

The following commands read Calendar's current state:

hey Calendar GET Version
hey Calendar GET SelectedDate
hey Calendar GET View

Dates use the unambiguous YYYY-MM-DD format. The available views are day, week and month.

hey Calendar SET SelectedDate TO "2026-10-15"
hey Calendar SET View TO week

Commands can also navigate to today or open Calendar windows:

hey Calendar DO Today
hey Calendar DO NewEvent
hey Calendar DO ManageCategories
